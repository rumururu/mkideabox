개인정보 처리방침

My App Manager (내 앱 장부) · 최종 수정일: 2026-09-07

조회한 수익 원자료와 일별 수익 장부는 온라인이나 MK Idea Box 서버에 저장하지 않고 이 기기에만 저장합니다. 다만 지표 조회를 위해 사용자가 연결한 서비스에 인증 요청을 직접 보내며, Google AdMob과 RevenueCat은 각각 광고와 My App Manager 구독에 필요한 정보를 처리합니다.

1. 운영자와 적용 범위

MK Idea Box가 제공하는 My App Manager는 앱 개발자의 매출과 백엔드 상태를 확인하는 도구입니다. 별도의 My App Manager 회원가입은 없습니다. 이 방침은 앱의 연결 설정, 지표 조회, 광고, 구독, 백업과 알림에 적용됩니다.

2. 기기에 보관하는 정보

  • 연결한 계정의 인증 토큰, 서비스 API 키, Supabase 관리 토큰과 Apple 서명용 개인키는 기기 보안 저장소를 이용해 보관합니다. 계정 이름·이메일 등 표시 정보, 프로젝트 주소와 앱 식별자 등 연결 설정은 기기 로컬 저장소에 보관합니다.
  • API에서 조회한 수익 원자료, 날짜·원 통화·제공자별 일별 수익 장부, 설치 수 등 지표와 백엔드 상태·사용량, 알림 기록, 화면 설정은 기기 로컬 저장소에 보관합니다. 이 수익 원자료와 장부를 온라인 동기화하거나 운영자 서버에 업로드하는 기능은 없습니다.
  • 구독 상태와 확인된 만료일은 보안 저장소에, 광고 표시 횟수·보상 종료 시각은 기기에 저장합니다. 광고 보상은 구독 상태를 변경하지 않습니다.

3. 연결한 외부 서비스와의 통신

사용자가 연결한 Google Play·Cloud Storage·AdMob, Apple App Store Connect, RevenueCat 및 Supabase API에 기기에서 직접 요청합니다. 해당 서비스에는 인증 토큰·서명된 요청과 필요한 앱·프로젝트 식별자, 조회 기간 등을 전송합니다. Apple 개인키는 기기에서 요청 서명에 사용합니다. 사용자가 추가한 백엔드 주소에도 상태 확인 요청을 보냅니다. 요청을 받는 서비스는 IP 주소 등 통신 정보를 처리할 수 있습니다.

등록 사용자 수는 Supabase Auth API에서 집계값을 읽습니다. API 응답에 일부 개별 사용자 정보가 포함될 수 있지만, 앱은 사용자 수 집계에 사용하며 해당 개별 정보의 별도 장부나 사용자 목록을 저장하지 않습니다. 환율은 Frankfurter에서 기준 통화로 조회하며 계정 키나 매출 금액은 보내지 않습니다.

연결 키와 조회한 사업 매출을 MK Idea Box가 관리하는 서버로 업로드하는 기능은 없습니다. 앱은 사용자가 선택한 연결 서비스의 API에서 기기로 직접 조회합니다. 아래 광고·구독 서비스의 정보 처리는 별개입니다.

4. Google OAuth와 Google 사용자 데이터

Google 계정을 연결하면 앱은 계정 표시를 위한 openid·email과 사용자가 선택한 기능에 필요한 Google Play Android Publisher, Cloud Storage 읽기, AdMob 읽기·보고서 또는 Firebase 읽기 권한을 요청할 수 있습니다. 실제 권한 문자열은 각각 androidpublisher, devstorage.read_only, admob.readonly, admob.report, firebase.readonly입니다. androidpublisher는 Google 승인 화면에서 Play 개발자 계정 보기 및 관리 권한으로 표시될 수 있지만, 앱 구현은 앱·리뷰·평점 등 조회 요청에만 사용합니다. 그 밖에도 승인 화면에 표시된 범위에서 프로젝트 목록, Play 보고서, AdMob 보고서와 Firebase 프로젝트 상태를 조회합니다.

이 중 일부는 Google이 민감 또는 제한 스코프로 분류할 수 있어 OAuth 앱 검증이 필요할 수 있습니다. 승인된 refresh token은 기기 보안 저장소에 보관하고 access token은 필요한 Google API 요청에 사용합니다. Google에서 받은 계정·보고서 데이터는 사용자가 요청한 화면과 지표 기능에만 사용하며 판매하거나 광고 타기팅에 사용하지 않고, MK Idea Box 서버로 전송하거나 저장하지 않습니다. 사용자는 Google 계정의 보안 설정에서 언제든 접근 권한을 철회할 수 있습니다.

5. 광고와 광고 빈도

무료 이용 중에는 Google AdMob 광고가 표시될 수 있습니다. 광고 SDK는 광고 제공·성과 측정·부정 이용 방지를 위해 광고 또는 앱 식별자, IP 주소와 이로부터 추정한 대략적 위치, 광고 상호작용, 기기·앱 진단 정보를 처리할 수 있습니다. 자세한 내용은 Google 개인정보처리방침 및 파트너 서비스 안내를 확인하세요.

AdMob은 법령상 동의, 지역, 광고 설정과 기기 선택에 따라 맞춤 광고, 비맞춤 광고 또는 제한 광고를 제공할 수 있습니다. 맞춤 광고는 과거 앱·웹 활동 등 이전에 수집된 정보를 광고 선택에 이용할 수 있습니다. 비맞춤 광고는 과거 행동을 타기팅에 사용하지 않지만 문맥·대략적 위치를 이용할 수 있고, 노출 빈도 제한과 집계 보고를 위해 허용된 식별자나 저장소를 사용할 수 있습니다.

iOS에서는 다른 회사의 앱·웹사이트에 걸친 광고 타기팅 또는 측정을 위해 광고 식별자(IDFA)에 접근하기 전에 앱 추적 투명성(ATT) 권한을 요청합니다. 거절하면 IDFA를 이용한 추적을 하지 않으며 기본 기능은 계속 이용할 수 있습니다. 광고는 비맞춤 또는 제한된 형태로 계속 표시될 수 있습니다. 광고·추적 선택은 표시되는 Google 동의 화면과 기기 개인정보 설정에서 관리할 수 있습니다.

추가 광고 빈도는 최근 매출과 앱 이용 시간을 기준으로 기기에서 결정합니다. 이 목적의 매출 금액이나 매출 구간을 AdMob 또는 RevenueCat 구매 SDK로 보내지 않습니다.

활성 구독 또는 유효한 광고 제거 보상 시간에는 광고를 표시하지 않습니다. 이미 발생한 광고 처리 기록은 해당 제공자의 정책에 따릅니다.

6. 구독과 RevenueCat

My App Manager 자체 구독은 Apple App Store 또는 Google Play에서 결제하고 RevenueCat으로 상품 조회, 구매 영수증 확인, 복원·갱신 및 혜택 적용을 처리합니다. 별도 회원 계정 대신 RevenueCat이 생성한 익명 앱 사용자 ID를 사용하며, RevenueCat은 이 ID와 상품·거래·구매 이력, 구독 상태 및 만료 정보 등을 처리합니다. 운영자는 RevenueCat 대시보드에서 구독 상태와 구매 통계를 확인할 수 있습니다.

사용자가 매출 조회를 위해 연결한 RevenueCat 계정과 My App Manager의 구독 SDK는 별개입니다. 연결한 계정 이메일·분석 API 키·사업 매출을 구매 SDK의 사용자 속성으로 등록하지 않습니다. 카드 번호 등 결제 수단 상세 정보는 앱이 받지 않습니다. RevenueCat 개인정보처리방침, Apple 개인정보처리방침 및 Google 방침이 함께 적용됩니다.

7. 백업·백엔드 점검·알림·기기 권한

  • 구독자의 설정 백업 파일은 자격증명을 포함할 수 있으며, 사용자가 정한 암호로 암호화합니다. 파일 저장·전달 위치는 사용자가 선택합니다. 선택한 위치가 클라우드 드라이브라면 해당 제공자가 파일을 보관할 수 있습니다. 앱 운영자에게 자동 전송하지 않습니다.
  • 백엔드 자동 감시를 켜면 앱이 사용자가 등록하거나 연결한 Supabase·Firebase·사용자 지정 상태 URL과 해당 API에 기기에서 직접 접근해 장애·중단·사용량을 확인합니다. 점검 결과와 알림 기록은 기기에 저장하고, 이슈는 기기 로컬 알림으로 표시합니다. MK Idea Box 서버가 대신 감시하거나 알림을 중계하지 않습니다. 알림에는 프로젝트 이름과 상태가 표시될 수 있으며, 알림·잠금 화면 표시와 백그라운드 실행은 기기 설정에서 관리할 수 있습니다.
  • Android에서 설치된 앱 아이콘을 읽어 앱 목록에 표시할 수 있습니다. 이 표시 목적의 설치 앱 목록을 광고·구독 SDK에 제공하지 않습니다.

8. 보관·삭제와 이용자의 선택

연결 자격증명은 앱 설정에서 삭제할 수 있습니다. 외부 서비스 접근 권한도 해당 제공자 설정에서 철회할 수 있습니다. 로컬 장부·설정은 기기에 보관되며, 앱 데이터 삭제 등 기기에서 제공하는 방법으로 제거할 수 있습니다. 내보낸 파일은 저장한 위치에서 별도로 삭제해야 합니다. iOS Keychain이나 OS 백업은 앱 삭제 후에도 남을 수 있으므로 앱 삭제만으로 모든 복사본이 지워진다고 보장하지 않습니다.

앱 삭제나 연결 계정 삭제는 스토어 구독을 해지하지 않습니다. 구독은 스토어에서 별도로 해지해야 합니다. 광고·구독 제공자가 보관하는 기록은 각 제공자의 처리방침과 법정 보관 의무에 따릅니다. 정보 열람·정정·삭제 요청은 아래 이메일로 접수할 수 있으며, 처리 가능한 범위와 외부 서비스 요청 경로를 안내합니다. 문의 시 API 키나 개인키를 보내지 마세요.

9. 아동·국외 처리·방침 변경

이 앱은 개발자를 위한 도구이며 만 14세 미만을 대상으로 하지 않습니다. 연결한 서비스와 광고·구독 제공자의 인프라는 사용자의 국가 밖에 있을 수 있습니다. 중요한 처리 변경은 이 페이지와 필요한 앱 안내에 반영합니다.
