My App Manager (내 앱 장부) · 최종 수정일 2026-08-30

요약: 이 앱은 여러분의 계정 정보를 기기 밖으로 내보내지 않습니다. 개발자가 운영하는 서버가 없습니다. 앱은 여러분이 연결한 스토어·광고 서비스에 여러분의 자격증명으로 직접 접속해 지표를 가져와 화면에 보여줄 뿐입니다.

제1조 (개발자 서버가 없습니다)

이 앱에는 회원가입이 없고, 개발자가 운영하는 서버도 없습니다. 따라서 여러분의 데이터가 개발자에게 전송되거나 개발자가 보관하는 일이 없습니다.

제2조 (기기에 저장되는 것)

항목저장 위치용도
Google 계정 인증 토큰(refresh token) 기기 안전 저장소
(Android Keystore / iOS Keychain)		 Google Play·AdMob 지표 조회
RevenueCat API 키, Supabase URL·키, App Store Connect 개인키(.p8) 기기 안전 저장소 해당 서비스 지표 조회 및 상태 확인
앱 프로필, 조회 설정, 마지막 조회 결과 기기 로컬 저장소 화면 구성 및 재실행 시 즉시 표시

이 값들은 기기를 벗어나지 않습니다. 앱을 삭제하면 함께 사라집니다.

제3조 (설정 내보내기)

기기를 바꿀 때 쓰는 "설정 옮기기" 기능은 위 자격증명을 포함한 꾸러미를 만듭니다. 이 꾸러미는 사용자가 정한 암호로 암호화(AES-256-GCM)되며, 암호 없이는 열 수 없습니다. 꾸러미를 어디로 보낼지는 전적으로 사용자가 결정합니다. 개발자는 이 꾸러미를 받지 않습니다.

제4조 (외부로 나가는 통신)

앱은 아래 서비스에 사용자 본인의 자격증명으로 직접 접속합니다. 모두 HTTPS 를 사용합니다.

  • Google Play Developer API · Google Cloud Storage (재무 리포트)
  • Google AdMob API
  • Apple App Store Connect API
  • RevenueCat API
  • 사용자가 등록한 Supabase·Firebase 등 백엔드 주소 (살아 있는지 확인)
  • 환율 조회 (frankfurter.app) — 계정 정보를 보내지 않습니다

제5조 (광고)

이 앱은 Google AdMob 배너 광고를 표시합니다. AdMob 은 광고 제공을 위해 광고 식별자 등을 수집할 수 있으며, 이는 Google 의 정책을 따릅니다. 자세한 내용은 Google 파트너 사이트 정책을 참고하세요.

Pro 기능을 사용하는 경우 광고가 표시되지 않습니다.

제6조 (알림 권한)

백그라운드 자동 갱신을 켠 경우, 조회 실패나 백엔드 중단이 감지되면 알림을 보냅니다. 알림 권한은 이 용도로만 사용하며, 거부해도 나머지 기능은 그대로 동작합니다.

제7조 (설치된 앱 조회)

Android 에서 앱 목록에 아이콘을 표시하기 위해 기기에 설치된 앱의 아이콘을 읽습니다. 이 정보는 화면 표시에만 쓰이며 저장하거나 전송하지 않습니다.

제8조 (아동)

이 앱은 앱 개발자를 위한 도구이며 만 14세 미만을 대상으로 하지 않습니다.

제9조 (계정 삭제)

앱 자체 계정이 없으므로 삭제할 계정이 없습니다. 앱 안에서 연결한 계정·키는 설정 화면에서 언제든 개별 삭제할 수 있고, 앱을 삭제하면 기기에 저장된 모든 값이 함께 제거됩니다.
