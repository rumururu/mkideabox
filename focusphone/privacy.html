보호자 계정과 원격 관리

보호자가 Google 계정으로 로그인하면 Google ID 토큰을 Supabase Auth에 전달해 계정을 확인합니다. 앱에는 사용자 ID·이메일·로그인 토큰이 저장됩니다. 가족 연결과 원격 관리를 사용하면 Supabase에 가족·기기 식별자와 별칭, 연결 정보, 허용 앱·시간표·도메인 등 정책, 정책 적용 결과와 기기 상태, 자녀의 허용 요청 사유·대상 앱·처리 결과가 저장됩니다.

자녀 앱은 원격 관리를 위해 런처에서 확인되는 설치 앱의 패키지명·표시 이름과 관리 가능 여부를 Supabase에 보냅니다. 설치 앱 목록은 서버 전송 대상입니다. 보호자는 연결된 기기의 원격 관리 화면에서 이를 확인합니다.

자녀폰에 남는 정보

자녀폰은 기기 안의 관리 설정과 PIN 관련 정보, 접속 도메인·IP 주소·포트·사용 앱 등의 접속 기록과 웹 필터 판정 기록을 저장합니다. 접속 기록은 원격 관리 서버로 보내지 않습니다. 접속 기록은 최대 7일·1,000건, 필터 기록은 최대 7일·500건까지 보관합니다. 원격 관리에 필요한 설정과 기기 상태는 별도로 서버에 전송됩니다.

자녀폰의 웹 필터가 허용한 DNS 질의는 외부 DNS 서비스 1.1.1.1로 전달됩니다. 앱은 정밀 위치 권한을 요청하거나 GPS 위치를 수집하지 않습니다.

선택 백업과 복원

사용자가 선택하면 자녀폰의 사진·동영상·문서·연락처·일정·설치 앱 목록을 보호자폰으로 직접 전송해, 보호자가 선택한 폴더에 저장합니다. 일정에는 입력된 장소가, 사진 원본에는 위치 메타데이터가 포함될 수 있습니다. 백업 파일은 원격 관리 서버에 저장하지 않습니다. 기기 간 백업 전송은 HTTPS를 사용하지만, 같은 Wi-Fi 안에서만 이동한다고 보장할 수는 없습니다. 선택한 폴더 또는 저장소 제공자의 별도 동기화 설정은 사용자가 확인해야 합니다. 저장된 백업 파일 자체를 앱이 암호화하지는 않습니다.

백업은 일부 사용자 콘텐츠를 옮기는 선택 기능이며, 앱 내부 데이터·채팅·문자·통화 기록을 포함한 휴대전화 전체 복사를 보장하지 않습니다. 백업본은 자동 만료되지 않습니다. 보호자 앱의 받은 백업 목록 또는 선택한 폴더에서 직접 삭제해야 합니다.

백업·복원 결과는 사용자가 직접 확인해야 합니다. 초기화 전에 다른 기기나 저장소에서 백업 파일이 열리는지 확인하세요. 백업·전송·복원·초기화 과정에서 발생하는 데이터 손실에 대해 서비스 제공자는 관련 법령이 허용하는 범위에서 책임을 지지 않습니다.

알림·결제와 외부 서비스

카메라는 QR 코드 인식에 사용됩니다. 알림을 사용하면 Firebase Cloud Messaging의 기기 토큰이 원격 알림에 사용되며 Supabase에 등록됩니다. 보호자 앱의 알림 등록은 앱 설정과 운영체제 알림 권한에 따릅니다. 보호자 앱에서 구독을 구매하면 Google Play Billing이 결제를 처리합니다. 구매 확인용 토큰은 Supabase로 전달되며, 서버에는 구매 토큰 원문과 해시, 상품·구독 상태가 저장됩니다. Google Play에 남는 결제 기록은 Google의 처리 범위입니다.

외부 서비스로는 Google 로그인·Google Play Billing·Firebase Cloud Messaging, Supabase 인증·원격 관리, 웹 필터의 외부 DNS 서비스를 사용합니다. 보호자 알림 메시지에는 알림 대상 확인을 위해 보호자 계정의 내부 식별자(무작위 UUID)가 포함되어 Firebase Cloud Messaging을 거쳐 전달됩니다. 알림과 QR 인식에 쓰이는 Google SDK(Firebase Installations, ML Kit 바코드 인식)는 Google 정책에 따라 앱 설치 식별자와 기능 사용·진단 정보를 Google에 보낼 수 있습니다. 앱에는 분석·광고·오류 수집 SDK가 없으며 Firebase Analytics 수집은 꺼져 있습니다. 원격 서버 통신과 선택 백업은 HTTPS를 사용합니다. 기기 간 로컬 관리 설정 전송에는 암호화되지 않은 HTTP 연결이 사용됩니다.

보관과 삭제

연결 중인 최신 관리 설정·기기 상태·설치 앱 목록과 결제 상태는 기능 제공 중 유지됩니다. 처리된 요청·이전 관리 명령·과거 설정 및 종료된 상태 장애 기록은 보관 조건을 충족하면 30일 이후 순차적으로 삭제합니다. 소유자가 연결되지 않은 미확인 구매 토큰은 생성 1일 후 삭제 대상입니다. 계정에 연결된 구매 토큰의 자동 삭제 기간은 정해져 있지 않습니다.

보호자가 자녀 기기의 원격 연결 해제를 하면 연결 세션과 알림 토큰은 삭제되지만, 해당 기기의 관리 설정·설치 앱 목록·요청·상태 기록은 보호자 계정이 삭제될 때까지(이력은 위 30일 기준에 따라) 서버에 남습니다. 모두 지우려면 계정 삭제를 요청하세요.

보호자 계정 삭제 요청이 처리되면 연결된 서버의 관리 설정·앱 목록·요청·상태·알림 토큰·계정에 연결된 결제 토큰과 인증 계정을 삭제합니다. 처리 실패 시 재시도하므로 요청 직후 완료를 보장하지 않습니다. 삭제 완료 확인 기록은 30일 이후 삭제 대상입니다. 재등록 방지를 위해 연결 해제된 기기의 설치 식별자와 철회 상태는 서버에 남으며 자동 삭제 기간은 정해져 있지 않습니다. 자녀폰의 로컬 설정·PIN·기기 관리 설정과 보호자폰의 선택 백업 파일은 계정 삭제로 지워지지 않습니다. Play 구독도 별도로 해지해야 합니다. 절차는 계정 삭제 안내를 확인하세요.
