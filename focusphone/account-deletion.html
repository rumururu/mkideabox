집중폰 계정 삭제

보호자 앱에서 요청

  1. 삭제할 Google 계정으로 집중폰 보호자 앱에 로그인합니다.
  2. 계정·로그인 → 계정 삭제 및 처리 상태 → 계정 삭제 요청을 엽니다.
  3. 삭제 대상을 확인하고 계정 삭제를 입력한 뒤, 같은 Google 계정으로 다시 인증하고 보호자 PIN을 확인합니다.
  4. 삭제 상태 확인에서 완료 여부를 확인합니다. 요청이 처리 중이거나 통신 결과가 불확실하면 상태를 다시 확인하세요. 완료 표시 전에는 삭제가 끝났다고 판단하지 마세요.

앱을 사용할 수 없을 때

앱을 사용할 수 없는 경우를 위한 삭제 요청 이메일은 mkideabox.feedback@gmail.com입니다. 이메일 요청은 계정 소유 확인 후 영업일 기준 3일 이내에 처리합니다.

삭제할 집중폰 계정의 Google 이메일 주소와 “집중폰 계정 삭제 요청”을 보내세요. 계정 소유 여부 확인이 필요할 수 있습니다. 비밀번호, PIN, 로그인·구매 토큰, 백업 파일은 보내지 마세요. 앱을 다시 설치할 필요는 없습니다.

삭제 범위와 남는 정보

삭제 요청이 처리되면 서버의 해당 계정, 가족 연결, 원격 관리 설정·설치 앱 목록·기기 상태·자녀 요청·알림 등록과 계정에 연결된 구매 토큰을 삭제합니다. 계정 삭제가 완료되지 않으면 다시 처리합니다. 삭제 완료 확인 기록은 30일 이후 삭제 대상입니다. 재등록 방지를 위한 기기 설치 식별자와 철회 상태는 서버에 남으며 자동 삭제 기간은 정해져 있지 않습니다.

계정 삭제는 자녀폰의 로컬 설정·PIN·기기 관리 설정이나 보호자폰의 선택 백업 파일을 삭제하지 않습니다. 백업본은 보호자 앱의 받은 백업 목록이나 선택한 저장 폴더에서 직접 삭제하세요. 자녀폰 설정 제거와 초기화는 별도 기기 절차입니다.

Google Play 구독은 계정 삭제와 별개입니다. 계속 청구되지 않도록 Google Play의 구독 관리에서 별도로 해지하세요. 구독 해지가 계정 삭제 요청의 선행 조건은 아닙니다.

데이터별 보관 내용은 개인정보 처리방침을 확인하세요.
