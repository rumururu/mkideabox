개인정보 처리방침

Claude Bridge (Remote IDE Bridge)

제1조 (수집 항목)

  • 서버 연결 정보 (URL, 포트 - 사용자 직접 입력)
  • 채팅 기록 (로컬 기기에만 저장)
  • 앱 설정 정보 (테마, 글꼴 크기 등)

제2조 (수집 목적)

  • Claude Code 서버와의 연결 유지
  • 채팅 기록 보관 및 이전 대화 참조
  • 사용자 맞춤 설정 저장

제3조 (보유 기간)

  • 서버 연결 정보: 사용자가 삭제할 때까지
  • 채팅 기록: 사용자가 삭제하거나 앱 삭제 시까지
  • 앱 설정: 앱 삭제 시까지

제4조 (제3자 제공)

본 앱은 개인정보를 제3자에게 제공하지 않습니다. 모든 데이터는 사용자 기기에만 저장됩니다.

제5조 (외부 서버 연결 안내)

  • 본 앱은 사용자가 직접 입력한 Claude Code 서버 주소로만 연결합니다.
  • 연결된 서버와의 통신 내용은 해당 서버 운영자의 정책을 따릅니다.
  • 앱 개발자는 사용자와 외부 서버 간의 통신 내용에 접근하지 않습니다.

제6조 (인터넷 권한 사용)

  • 본 앱은 Claude Code 서버와 WebSocket 연결을 위해 인터넷 권한을 사용합니다.
  • 사용자가 입력한 서버 주소 외의 외부 서버로 데이터를 전송하지 않습니다.

제7조 (이용자의 권리)

이용자는 앱 내에서 언제든지 채팅 기록 및 서버 연결 정보를 삭제할 수 있습니다.

제8조 (보안 조치)

모든 데이터는 사용자 기기의 로컬 저장소에만 저장되며, 외부 서버로 전송되지 않습니다.
