Claude Bridge (Remote IDE Bridge)

본 앱은 계정 시스템이 없습니다

Claude Bridge는 회원가입이나 로그인 없이 사용할 수 있는 로컬 앱입니다. 모든 데이터는 사용자의 기기에만 저장됩니다.

앱 내 데이터 삭제 방법

  1. 앱을 실행합니다.
  2. 설정 메뉴로 이동합니다.
  3. 데이터 관리를 선택합니다.
  4. 채팅 기록 삭제 또는 모든 데이터 삭제를 탭합니다.

삭제되는 데이터

  • 채팅 기록 (대화 내용)
  • 서버 연결 정보 (URL, 포트)
  • 앱 설정 (테마, 글꼴 크기 등)

앱 삭제로 완전 삭제

앱을 삭제하면 기기에 저장된 모든 데이터가 자동으로 삭제됩니다.

본 앱은 외부 서버에 사용자 데이터를 저장하지 않으므로, 앱 삭제만으로 모든 데이터가 완전히 제거됩니다.
