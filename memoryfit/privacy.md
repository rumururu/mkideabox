# 개인정보 처리방침

**MemoryFit (FSRS 기반 암기 앱)**  
최종 업데이트: 2026년 5월 6일

## 제1조 (수집 항목)

- 기기 식별자 (익명화된 Device ID)
- 계정 정보 (이메일, 로그인 제공자 식별자) - 로그인 사용 시
- 학습 데이터 (덱, 카드 내용, 복습 기록, 학습 통계)
- 연락처 정보 (이름, 전화번호) - 연락처 덱 생성 시, 선택
- 카메라 촬영 이미지 또는 사용자가 선택한 이미지 - 이미지 카드 생성 시, 선택
- 음성 입력 - 음성 답변 기능 사용 시, 선택
- AI 기능 사용 시 사용자가 입력하거나 가져온 학습 콘텐츠, PDF/웹/영상 등에서 추출된 텍스트, 생성 옵션, 이미지 프롬프트, 요청 처리에 필요한 기술 로그
- 결제 및 크레딧 사용 이력 (구매 상품 ID, 거래 식별자, 크레딧 사용 내역)

## 제2조 (수집 및 이용 목적)

- FSRS 알고리즘 기반 최적화된 복습 스케줄 제공
- 덱, 카드, 복습 기록 저장 및 동기화
- AI 카드 자동 생성 및 AI 이미지 생성
- 연락처에서 이름/전화번호 학습 카드 생성
- 학습 통계 및 진행률 추적
- 크레딧 구매, 차감, 환불 및 부정 사용 방지
- 앱 기능 개선, 오류 분석, 보안 및 악용 방지

## 제3조 (AI 기능 및 제3자 AI 처리)

- MemoryFit은 사용자가 AI 카드 생성 또는 AI 이미지 생성을 실행한 경우에만 AI 처리를 수행합니다.
- 처리 목적: 학습 카드 자동 생성, 학습용 이미지 생성, 요청 처리 및 크레딧 사용 이력 관리
- 전송 항목: 사용자가 입력하거나 가져온 학습 콘텐츠, PDF/웹/영상 등에서 추출된 텍스트, 생성 옵션(언어, 난이도, 카드 유형 등), AI 이미지 생성을 위한 프롬프트, 요청 처리에 필요한 기술 로그
- 처리 경로: AI 요청은 MemoryFit 서버(Supabase Edge Functions)를 거쳐 처리됩니다.
- 제3자 AI 제공자: Google Gemini API
- 전송 시점: 사용자가 AI 카드 생성 또는 AI 이미지 생성을 실행할 때
- 비전송 범위: 사용자가 AI 생성을 실행하지 않은 기존 로컬 덱과 카드는 제3자 AI 제공자에게 전송되지 않습니다.
- 보유 및 로그: AI 요청 데이터는 기능 제공을 위해 처리되며, 보안, 악용 방지, 운영, 법적 의무 이행을 위한 서비스 로그에 관련 제공자의 약관과 정책에 따라 보관될 수 있습니다.
- 앱 내 확인 경로: Settings > AI Settings > AI Data Use

## 제4조 (보유 기간)

- 학습 데이터: 앱 삭제, 계정 삭제 또는 사용자 삭제 요청 시까지
- 연락처 정보: 기기 내에서만 처리되며, 서버로 전송하지 않습니다.
- 카메라 촬영 이미지 및 음성 입력: 해당 기능 제공을 위해 기기 내에서 처리됩니다. 사용자가 AI 기능에 직접 입력하거나 전송하지 않는 한 제3자 AI 제공자에게 전송하지 않습니다.
- AI 요청 데이터: 기능 제공을 위해 처리되며, 보안, 악용 방지, 운영, 법적 의무 이행을 위한 서비스 로그에 관련 제공자의 약관과 정책에 따라 보관될 수 있습니다.
- 결제 및 크레딧 이력: 거래 확인, 환불, 회계 및 분쟁 대응에 필요한 기간 동안 보관될 수 있습니다.
- 기기 식별자: 앱 삭제 또는 사용자 삭제 요청 시까지

## 제5조 (제3자 제공)

- **Google Gemini API**: AI 카드 생성 및 AI 이미지 생성 기능 사용 시
  - 제공 항목: 사용자가 입력하거나 가져온 학습 콘텐츠, PDF/웹/영상 등에서 추출된 텍스트, 생성 옵션, 이미지 프롬프트, 요청 처리에 필요한 기술 로그
  - 목적: 학습 카드 자동 생성 및 학습용 이미지 생성
- **Apple In-App Purchase / RevenueCat**: 크레딧 구매 및 결제 검증 시
  - 제공 항목: 구매 상품 ID, 거래 식별자, 결제 검증에 필요한 정보
  - 목적: 결제 처리, 구매 복원, 크레딧 지급 및 환불 처리

그 외 법령에 따른 경우를 제외하고는 개인정보를 제3자에게 제공하지 않습니다.

## 제6조 (개인정보 처리 위탁 및 국외 처리)

- **Supabase Inc. (미국)**: 데이터베이스 호스팅, 인증, 서버 기능 제공
- **Google Gemini API / Google LLC 또는 관련 Google 계열사**: AI 요청 처리
  - 처리 항목: AI 기능 실행 시 전송되는 콘텐츠, 생성 옵션, 이미지 프롬프트, 기술 로그
  - 관련 정책: https://ai.google.dev/gemini-api/docs/logs-policy

## 제7조 (연락처 접근 안내)

- 본 앱은 연락처에서 이름과 전화번호를 읽어 학습 카드를 생성하는 기능을 제공합니다.
- 연락처 정보는 기기 내에서만 처리되며, 서버로 전송되지 않습니다.
- 연락처 접근은 선택 사항이며, 해당 기능을 사용하지 않으면 권한을 허용하지 않아도 됩니다.

## 제8조 (카메라/마이크 사용 안내)

- 카메라: 이미지 카드 생성에 사용됩니다.
- 마이크: 음성 답변 기능 및 TTS(텍스트 음성 변환)에 사용됩니다.
- 촬영 이미지 및 음성은 기본적으로 기기 내에서 처리됩니다. 사용자가 별도로 AI 기능에 입력하거나 전송하지 않는 한 제3자 AI 제공자에게 전송하지 않습니다.

## 제9조 (오프라인 기능)

본 앱은 오프라인 학습을 지원합니다. 오프라인 모드에서는 AI 생성, 백업, 결제 확인 등 네트워크가 필요한 기능을 제외하고 학습 데이터가 기기 내에서 처리됩니다.

## 제10조 (이용자의 권리)

이용자는 언제든지 개인정보 열람, 정정, 삭제, 처리정지, 동의 철회를 요청할 수 있습니다. 앱 설정의 계정 삭제 기능 또는 이메일을 통해 요청할 수 있습니다.

## 제11조 (보안 조치)

MemoryFit은 HTTPS 통신, Supabase Row Level Security, 접근 권한 제한, 기기 내 저장소 보호 등 합리적인 기술적·관리적 보호조치를 적용합니다.

## 제12조 (아동 개인정보)

MemoryFit은 아동으로부터 민감한 개인정보를 의도적으로 수집하지 않습니다. 보호자는 필요한 경우 개인정보 삭제를 요청할 수 있습니다.

## 제13조 (변경 고지)

개인정보 처리방침이 변경되는 경우 앱 또는 공개 웹페이지를 통해 고지합니다.
