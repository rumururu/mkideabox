# 개인정보 처리방침

**MemoryFit (FSRS 기반 암기 앱)**

## 제1조 (수집 항목)

- 기기 식별자 (익명화된 Device ID)
- 학습 데이터 (카드 내용, 복습 기록)
- 앱 사용 통계 (학습 시간, 진행률)
- 카메라 촬영 이미지 (이미지 카드 생성 시, 선택)
- 음성 입력 (음성 답변 기능 사용 시, 선택)

## 제2조 (수집 목적)

- FSRS 알고리즘 기반 최적화된 복습 스케줄 제공
- AI 카드 자동 생성 (Gemini AI)
- 학습 통계 및 진행률 추적
- 앱 기능 개선 및 오류 분석

## 제3조 (보유 기간)

- 학습 데이터: 앱 삭제 또는 사용자 삭제 요청 시까지
- AI 생성 요청 데이터: 처리 완료 후 즉시 삭제
- 기기 식별자: 앱 삭제 시까지

## 제4조 (제3자 제공)

- **Google Gemini AI**: AI 카드 자동 생성 기능 사용 시
  - 제공 항목: 사용자가 입력한 학습 콘텐츠 (텍스트, URL, PDF 내용)
  - 목적: 플래시카드 자동 생성

그 외 법령을 제외하고는 개인정보를 제3자에게 제공하지 않습니다.

## 제5조 (개인정보 처리 위탁)

- **데이터베이스 호스팅 및 AI 기능**: Supabase Inc. (미국)

## 제6조 (카메라/마이크 사용 안내)

- 카메라: 이미지 카드 생성 및 PDF/문서 스캔에 사용됩니다.
- 마이크: 음성 답변 기능 및 TTS(텍스트 음성 변환)에 사용됩니다.
- 촬영 이미지 및 음성은 기기 내에서 처리되며, AI 카드 생성 요청 시에만 서버로 전송됩니다.

## 제7조 (오프라인 기능)

본 앱은 완전한 오프라인 학습을 지원합니다. 오프라인 모드에서는 모든 데이터가 기기 내에서만 처리되며 외부로 전송되지 않습니다.

## 제8조 (이용자의 권리)

이용자는 언제든지 열람, 정정, 삭제를 요청할 수 있으며 앱 설정 또는 이메일로 신청 가능합니다.

## 제9조 (보안 조치)

HTTPS 통신, Supabase RLS, 기기 내 암호화로 안전하게 데이터를 보호합니다.
