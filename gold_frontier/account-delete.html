계정 및 데이터 삭제 안내

Gold Frontier 3D | 최종 업데이트: 2026년 8월 1일

안내: Gold Frontier 3D는 Google/Apple 계정으로 로그인해 클라우드 저장을 사용할 수 있는 게임입니다. 로그인 계정과 수집된 모든 데이터는 앱 안에서 직접, 즉시, 영구적으로 삭제할 수 있습니다.

1. 계정 삭제 (앱 내 · 권장)

  1. 게임 실행 후 화면 우측 상단의 설정(⚙) 버튼을 탭합니다.
  2. 시스템 패널의 계정 섹션에서 "계정 삭제" 버튼을 탭합니다.
  3. 확인 안내가 표시되면 8초 이내에 "계정 삭제" 버튼을 한 번 더 탭합니다.

삭제가 완료되면 "계정이 삭제되었습니다" 안내와 함께 타이틀 화면으로 돌아갑니다. 이 절차는 되돌릴 수 없습니다.

삭제되는 데이터

  • 로그인 계정 정보: 이메일 주소, 표시 이름, 계정 고유 식별자(UID)
  • 클라우드 세이브 데이터 전체 (서버 측 즉시 삭제)
  • 서버에 업로드된 오류 진단 로그
  • 기기에 저장된 게임 저장 슬롯(1~3) 및 로그인 인증 정보

서버 측 삭제가 완료된 뒤에만 기기 데이터가 정리되므로, 네트워크 오류 시에는 아무것도 삭제되지 않고 다시 시도할 수 있습니다.

2. 게스트 데이터 삭제 (로그인하지 않은 경우)

방법 A — 앱 내 저장 슬롯 초기화

  1. 타이틀 화면에서 초기화할 저장 슬롯(1~3)을 선택합니다.
  2. "새 게임 시작"을 선택하고 확인하면 해당 슬롯의 진행 데이터가 즉시 삭제됩니다.

방법 B — 앱 삭제

  • Android: 앱 아이콘 길게 누르기 → "앱 정보" → "제거"
  • iOS: 앱 아이콘 길게 누르기 → "앱 삭제" → "삭제"

게스트 플레이 데이터는 외부 서버로 전송되지 않으므로, 앱 삭제만으로 모든 데이터가 완전히 제거됩니다.

3. 광고 식별자, 트래킹 데이터

본 앱은 광고 식별자(IDFA, GAID)를 수집하지 않으며, 제3자 분석/광고 SDK를 통합하지 않습니다. 따라서 별도로 삭제를 요청할 트래킹 데이터가 존재하지 않습니다.

4. 이메일로 삭제 요청 (대체 수단)

앱에 접근할 수 없는 경우 등에는 아래 이메일로 삭제를 요청하실 수 있습니다. 로그인에 사용한 이메일 주소를 알려주시면 영업일 기준 7일 이내에 계정과 데이터를 삭제하고 회신드립니다.
