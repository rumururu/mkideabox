계정 및 데이터 삭제 안내

Gold Frontier — Lost Dutchman's Secret

안내: Gold Frontier는 회원가입과 로그인이 없는 싱글플레이 게임입니다. 별도의 "계정"이 존재하지 않으며, 모든 게임 데이터는 사용자 기기 내부에만 저장됩니다. 따라서 외부 서버에 남아 있는 정보가 없습니다.

1. 게임 데이터 삭제 방법

방법 A — 앱 내 저장 슬롯 초기화 (특정 진행 데이터만)

  1. 본 앱 실행 → 타이틀 화면
  2. 초기화할 저장 슬롯 선택 (슬롯 1~3)
  3. "새 게임 시작" 선택
  4. "슬롯 N의 저장을 지우고 처음부터 시작한다" 확인 다이얼로그에서 "새로 시작" 탭

해당 슬롯의 모든 진행 데이터(플레이어 위치, 인벤토리, 퀘스트 상태 등)가 즉시 삭제되고 처음부터 시작됩니다.

방법 B — 앱 삭제 (모든 데이터 완전 삭제)

본 앱을 기기에서 삭제하면, 본 앱과 관련된 모든 로컬 데이터가 함께 완전히 삭제됩니다.

  • Android: 홈 화면에서 앱 아이콘을 길게 눌러 "앱 정보" → "제거" 또는 "삭제"
  • iOS: 홈 화면에서 앱 아이콘을 길게 눌러 "앱 삭제" → "삭제"

2. 외부 서버에 남아 있는 정보

없습니다. 본 앱은 어떤 사용자 데이터도 외부 서버로 전송하지 않으므로, 회사가 보관하는 사용자 정보가 존재하지 않습니다. 별도의 삭제 요청 절차가 필요 없습니다.

3. 광고 식별자, 트래킹 데이터

본 앱은 광고 식별자(IDFA, GAID)를 수집하지 않으며, 제3자 분석/광고 SDK를 통합하지 않습니다. 따라서 사용자의 디바이스 식별자 기반 트래킹 데이터도 존재하지 않습니다.
