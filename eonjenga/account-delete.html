데이터 삭제 안내

언젠가 (Eonjenga)

언젠가 앱은 회원가입·로그인 없이 동작합니다. 별도의 "계정"이 존재하지 않으므로 일반적인 의미의 "계정 삭제" 절차는 없습니다. 대신 아래 경로로 모든 관련 데이터를 즉시 또는 수동으로 삭제할 수 있습니다.

1. 기기 로컬 데이터 삭제

작성한 여행 일기, 좋아요/위시리스트, 마지막 선택 목적지 등 모든 사용자 데이터는 이용자 기기의 로컬 저장소에만 보관됩니다. 두 가지 방법으로 즉시 전량 삭제할 수 있습니다.

방법 A — 앱 삭제 (권장)

  1. 기기 홈 화면 또는 설정에서 언젠가 앱을 삭제합니다.
  2. 운영체제가 앱 데이터/캐시를 전량 제거하며, 일기·위시리스트·로컬 설정이 즉시 삭제됩니다.
  3. 회사 서버에는 로컬 데이터의 백업이 존재하지 않으므로 추가 절차가 필요 없습니다.

방법 B — 앱 내 초기화 (향후 제공)

앱 설정에서 "모든 기록 지우기" 메뉴를 통해 일기/위시리스트 일괄 삭제 기능을 제공할 예정입니다 (v1.0.0 업데이트 예정).

2. 서버에 저장된 데이터 삭제

서버(Supabase)에 저장되는 데이터는 다음으로 한정됩니다.

  • 이용자가 직접 보낸 큐레이션 정보 오류 신고 본문
  • 신고 시각
  • 앱 설치 시 생성된 익명 디바이스 ID (개인식별 불가)

위 데이터의 삭제를 원하시면 아래 연락처로 요청해주세요.

3. 삭제 후 복구 여부

  • 앱 삭제 후 재설치하여도 이전 데이터는 복구되지 않습니다 (클라우드 백업 없음).
  • 서버에서 삭제된 오류 신고 데이터는 복구되지 않습니다.
