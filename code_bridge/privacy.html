개인정보 처리방침

Code Bridge | 시행일: 2025년 2월 1일

mkideabox(이하 "회사")는 정보통신망 이용촉진 및 정보보호 등에 관한 법률, 개인정보보호법 등 관련 법령상의 개인정보보호 규정을 준수하며, 이용자의 개인정보 보호에 최선을 다하고 있습니다.

제1조 (수집하는 개인정보 항목)

필수항목 (소셜 로그인 사용 시)

  • 소셜 로그인 정보: 소셜 계정 고유 ID (Google ID, Apple ID)
  • 프로필 정보: 이메일 (소셜 계정 제공 시)

서비스 이용 시 자동 수집 정보

  • 기기 정보 (기기 식별자, 운영체제, 앱 버전)
  • 구독 상태 및 결제 정보 (RevenueCat을 통해 관리)

로컬 전용 사용 시

소셜 로그인 없이 앱을 사용하는 경우, 회사는 개인정보를 수집하지 않습니다. 모든 데이터는 사용자의 기기에만 저장됩니다.

제2조 (개인정보의 수집 및 이용목적)

  • 서비스 제공: 회원 식별, 구독 관리, 무료 체험 기간 관리
  • 회원 관리: 회원제 서비스 이용, 본인 확인
  • 결제 처리: 구독 결제 및 갱신 관리 (Apple/Google 스토어 연동)
  • 고객 지원: 문의 응대, 서비스 안내

제3조 (개인정보의 보유 및 이용기간)

회원의 개인정보는 원칙적으로 회원 탈퇴 시까지 보유합니다. 다만, 관계 법령에 따라 보존이 필요한 경우 해당 기간 동안 보관합니다.

  • 구독/결제 기록: 5년 (전자상거래법)

제4조 (개인정보의 제3자 제공)

회사는 원칙적으로 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만, 다음의 경우에는 예외로 합니다:

  • 이용자가 사전에 동의한 경우
  • 법령의 규정에 의거하거나, 수사 목적으로 법령에 정해진 절차와 방법에 따라 수사기관의 요구가 있는 경우

제5조 (개인정보 처리 위탁)

회사는 서비스 제공을 위해 다음과 같이 개인정보 처리를 위탁합니다:

  • Firebase (Google): 사용자 인증 및 데이터 저장
  • RevenueCat: 구독 결제 관리
  • Apple App Store / Google Play Store: 결제 처리

제6조 (환불 정책)

구독 환불은 Apple App Store 또는 Google Play Store 정책에 따라 각 스토어에서 직접 처리됩니다.

  • iOS: reportaproblem.apple.com에서 환불 요청
  • Android: Google Play 앱 → 프로필 → 결제 및 구독에서 환불 요청

제6조 (개인정보의 파기)

회원 탈퇴 시 개인정보는 지체 없이 파기됩니다.

  • 전자적 파일: 복구 불가능한 방법으로 영구 삭제

제7조 (이용자의 권리)

이용자는 언제든지 다음 권리를 행사할 수 있습니다:

  • 개인정보 열람 요구
  • 개인정보 정정 요구
  • 개인정보 삭제 요구
  • 처리정지 요구

권리 행사는 앱 내 설정 또는 고객센터를 통해 가능합니다.

제8조 (개인정보 보호를 위한 기술적/관리적 대책)

  • 암호화: 통신 데이터 SSL/TLS 암호화
  • 접근 통제: 개인정보처리시스템에 대한 접근 권한 제한
  • 로컬 데이터: 사용자 기기 내 로컬 저장으로 외부 노출 최소화

제9조 (서버 연결 및 데이터 처리)

Code Bridge는 사용자의 PC에서 실행되는 서버와 연결하여 동작합니다:

  • 코드 파일 및 프로젝트 정보는 사용자의 PC 서버에서 처리됩니다.
  • AI 채팅 기능은 사용자가 설정한 API 키를 통해 외부 AI 서비스(Anthropic, OpenAI 등)와 통신합니다.
  • 회사는 사용자의 코드 내용이나 AI 대화 내용을 수집하거나 저장하지 않습니다.

제10조 (개인정보 보호책임자)

장미 / 이메일: mkideabox@gmail.com

제11조 (개인정보처리방침의 변경)

이 개인정보처리방침은 법령, 정책의 변경 또는 회사 내부 방침에 따라 변경될 수 있으며, 변경 시 앱 내 공지사항을 통해 안내드립니다.
