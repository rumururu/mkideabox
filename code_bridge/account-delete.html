계정 삭제 안내

Code Bridge

로컬 전용 사용자

소셜 로그인 없이 앱을 사용하셨다면, 계정이 생성되지 않았습니다. 앱을 삭제하시면 모든 로컬 데이터가 제거됩니다.

앱 내 계정 삭제 방법

  1. 앱을 실행합니다.
  2. 설정 탭으로 이동합니다.
  3. 계정 섹션을 찾습니다.
  4. 계정 삭제를 탭합니다.
  5. 안내에 따라 삭제를 확인합니다.

계정 삭제 시 주의사항

계정을 삭제하면 다음 정보가 영구적으로 삭제되며 복구할 수 없습니다:

  • 프로필 정보 (이메일, 소셜 로그인 연결)
  • 무료 체험 기록
  • 등록된 서버 정보

구독 해지 안내

계정 삭제 전에 활성 구독이 있다면 먼저 구독을 해지해 주세요.

  • iOS: 설정 앱 → Apple ID → 구독 → Code Bridge → 구독 취소
  • Android: Play Store → 프로필 → 결제 및 구독 → 구독 → Code Bridge → 구독 취소

계정을 삭제해도 스토어에서 구독을 직접 취소하지 않으면 결제가 계속될 수 있습니다.

삭제되는 데이터

  • Firebase 계정 정보 (이메일, 소셜 로그인 연결)
  • 무료 체험 시작일 기록
  • 등록된 PC 서버 목록

삭제되지 않는 데이터

  • PC 서버에 저장된 프로젝트 파일 (사용자 PC에 존재)
  • 스토어 결제/구독 기록 (Apple/Google에서 관리)

삭제 처리 기간

계정 삭제 요청 후 즉시 모든 데이터가 삭제됩니다.
