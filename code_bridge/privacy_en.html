Privacy Policy

Code Bridge | Effective Date: February 1, 2025

mkideabox ("Company") complies with privacy protection regulations under applicable laws and is committed to protecting user privacy.

1. Information We Collect

Required Information (when using Social Login)

  • Social login information: Social account unique ID (Google ID, Apple ID)
  • Profile information: Email (when provided by social account)

Automatically Collected Information

  • Device information (device identifier, operating system, app version)
  • Subscription status and payment information (managed through RevenueCat)

Local-Only Usage

When using the app without social login, the Company does not collect any personal information. All data is stored only on the user's device.

2. Purpose of Collection and Use

  • Service provision: User identification, subscription management, free trial period management
  • Member management: Membership service usage, identity verification
  • Payment processing: Subscription payment and renewal management (Apple/Google Store integration)
  • Customer support: Inquiry response, service guidance

3. Retention Period

Personal information is retained until membership withdrawal. However, if retention is required by applicable laws, data will be kept for the required period.

  • Subscription/payment records: 5 years (as required by e-commerce laws)

4. Disclosure to Third Parties

The Company does not provide user personal information to third parties, except in the following cases:

  • When the user has given prior consent
  • When required by law or requested by investigative authorities following legal procedures

5. Data Processing Partners

The Company partners with the following services for service provision:

  • Firebase (Google): User authentication and data storage
  • RevenueCat: Subscription payment management
  • Apple App Store / Google Play Store: Payment processing

6. Refund Policy

Subscription refunds are processed directly through Apple App Store or Google Play Store according to their respective policies.

  • iOS: Request refund at reportaproblem.apple.com
  • Android: Request refund via Google Play app → Profile → Payments & subscriptions

7. Data Deletion

Personal information is deleted promptly upon membership withdrawal.

  • Electronic files: Permanently deleted using irrecoverable methods

8. User Rights

Users may exercise the following rights at any time:

  • Request to access personal information
  • Request to correct personal information
  • Request to delete personal information
  • Request to suspend processing

Rights can be exercised through in-app settings or customer support.

9. Security Measures

  • Encryption: SSL/TLS encryption for data transmission
  • Access control: Restricted access to personal information processing systems
  • Local data: Minimized external exposure through local device storage

10. Server Connection and Data Processing

Code Bridge connects to a server running on the user's PC:

  • Code files and project information are processed on the user's PC server.
  • AI chat functionality communicates with external AI services (Anthropic, OpenAI, etc.) through API keys configured by the user.
  • The Company does not collect or store user code content or AI conversation content.
