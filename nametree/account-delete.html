계정 삭제 안내

나모트리(NamoTree)

앱 내 계정 삭제 방법

  1. 앱을 실행합니다.
  2. 왼쪽 상단 메뉴 버튼을 탭합니다.
  3. 드로어 하단의 계정 삭제를 선택합니다.
  4. 안내에 따라 삭제를 확인합니다.

⚠️ 계정 삭제 시 주의사항

계정을 삭제하면 다음 정보가 영구적으로 삭제되며 복구할 수 없습니다:

  • 모든 인물·관계·메모 데이터 (모든 트리)
  • 입력 히스토리 및 자연어 원문 로그
  • 사용자 구조 피드백 및 개인화 설정
  • 계정 정보 (이메일, UID, 프로필)

삭제되는 데이터

  • 개인정보: 이메일, 이름, 소셜 로그인 ID
  • 서비스 데이터: 모든 트리 노드, 관계, 메모, 자연어 원문
  • 설정 정보: 알림 설정, AI 모드 설정, 카테고리 분류

삭제 처리 기간

계정 삭제 요청 후 24시간 이내에 모든 데이터가 삭제됩니다. 단, 관련 법령에 따라 보존이 필요한 정보는 해당 법령에서 정한 기간 동안 보관 후 파기됩니다.
