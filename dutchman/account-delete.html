계정 및 데이터 삭제 안내

Gold Frontier: Dutchman's Curse

안내: Dutchman's Curse 는 회원가입과 로그인이 없는 싱글플레이 게임입니다. 별도의 "계정"이 존재하지 않으며, 모든 게임 데이터는 사용자 기기 내부에만 저장됩니다. 따라서 외부 서버에 남아 있는 정보가 없습니다.

1. 게임 데이터 삭제 방법

방법 A — 앱 내 설정에서 진행 초기화

  1. 본 앱 실행 → 타이틀 화면 → "설정"
  2. "진행 데이터 초기화" 선택
  3. 확인 다이얼로그 진행 → Dust 잔액 / 해금 / 통계 / 튜토리얼 진행이 모두 0으로 리셋됨

※ 앱 자체는 그대로 유지되며, 새로 처음부터 플레이할 수 있습니다.

방법 B — 앱 삭제 (모든 데이터 영구 삭제)

본 앱을 기기에서 제거하면 게임 데이터가 영구적으로 삭제됩니다.

Android

  1. 설정 → 앱 → "Gold Frontier: Dutchman's Curse" 선택
  2. "제거" 또는 "삭제" 선택

또는 홈 화면에서 앱 아이콘 길게 누르기 → "제거"

iOS

  1. 홈 화면에서 앱 아이콘을 길게 눌러 흔들리게 함
  2. "−" 또는 "x" 버튼을 탭하여 "앱 삭제" 선택

2. 외부 서버 데이터에 대해

본 앱은 사용자 데이터를 외부 서버로 전송하지 않습니다. 따라서 회사가 보관 중인 사용자 정보는 존재하지 않으며, 별도의 외부 데이터 삭제 요청 절차는 필요하지 않습니다.

3. 광고 및 분석

본 앱은 광고를 표시하지 않으며 외부 분석(Analytics) SDK 도 사용하지 않습니다. 광고 식별자(IDFA, GAID)도 수집하지 않습니다.
